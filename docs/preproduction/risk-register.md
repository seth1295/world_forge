# Pre-production Risk Register

**Status:** Evidence updated after Gate A, generator PRs #1/#2, and Gate B/C consumer testing; independent Gate C QA remains pending.
**Owner:** WorldForge Main Lead.  
**Last reviewed:** 2026-10-30.  
**Performance efficiency:** Out of scope for pre-production QA and exit decisions.

Priority orders investigation by how early the risk can invalidate the required generator-to-Godot proof; it is not a severity grade or a performance target. Ratings stay provisional until the relevant experiment supplies evidence.

This proves the new producer path, not the inherited BeamNG application path. | Keep the old BeamNG-coupled service and asset paths out of the new producer; maintain separate review if inherited code is migrated. | Independent prototype producer demonstrated; broader inherited server decoupling remains open. |
| R2 | Real prototype elevation is available, traceable, reproducible and semantically correct for the chosen region. | Both official 3DEP source rasters, sidecars and product records are locally SHA-256 checked and provenance/rights reviewed. ## Evidence discipline

This is an open-risk list, not a completion declaration. Update each row with a current commit, test command/result, artifact or source citation as evidence becomes available. Keep observed facts, engineering hypotheses and not-run checks distinct. Resolve critical assumptions with functional and geographic tests; do not add performance thresholds.
