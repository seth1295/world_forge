# Global geographic data and fidelity policy

**Status:** Active prototype policy selected by the WorldForge Main Lead on 2026-10-30. This records project source selection and engineering requirements; it is not legal advice or a release-rights clearance.

**Scope:** Global land elevation, ocean/bathymetry, roads, buildings, water, land cover and vegetation-class inputs. No gameplay systems or performance targets are established here.

## Source policy

Use only traceable public sources whose documented terms permit the intended prototype use. Paid sources, restricted Copernicus releases and noncommercial-only sources are excluded. A missing source is an explicit coverage gap or a labelled, permitted lower-resolution fallback; it is never silently replaced by synthetic geography presented as observed data.

Do not describe it as bare earth. Do not resample source terrain into a different grid or datum without recording the method and resulting source status.

## Tile provenance and status semantics

Every generated tile layer must carry provider, product and release/version; retrieval/source snapshot identity; horizontal CRS, axis order, datum and units; source vertical datum and height type; conversion method and version where used; original data and generated payload checksums; source uncertainty/quality metadata; rights and required attribution; and the source/fallback class. For CopDEM geoid conversion, retain `H_EGM2008`, `N_EGM2008`, `h_ellipsoid`, the geoid grid version/checksum and interpolation method. For GEBCO, retain the MSL/mixed-datum warning and Type Identifier provenance. For Overture, retain feature-level `sources[]` fields and licenses. For WorldCover, retain class mapping and the product version.

Use the layer status vocabulary `ready`, `partial`, `no_source_coverage`, `not_generated`, `failed`, and `cancelled`:

- `ready` means the declared layer query completed and its payload passed validation. A valid query with zero features uses `ready` with `feature_count: 0` and explicit query/coverage metadata; it does not mean surveyed absence.
- `partial` may be installed only when the consumer explicitly allows it and the missing coverage, source quality, fallback source and/or uncertainty are visible to downstream rendering and inspection.
- `no_source_coverage` triggers a configured, lawful fallback or remains an explicit coverage gap. It must not be encoded as a valid empty geographic layer.
- `not_generated`, `failed`, and `cancelled` remain distinguishable from ready/empty data. A stale or cancelled asynchronous completion is not installed.

The current bundle/schema and generator work must preserve this information. No layer can inherit terrain's vertical meaning by default; each source layer carries its own CRS and vertical semantics. The global address key remains normalized WGS84 longitude/latitude and is not a declaration that a source's original geodetic realization or epoch has been transformed. Until the generator emits a pinned grid revision and computed SHA-256 in the bundle, CopDEM EGM2008 conversion is not verified for real terrain and must not be reported as complete. Keep the geoid data in an on-demand generator cache, not the parent repository.

## Geographic fidelity criteria

These are Main Lead-selected correctness criteria, not source-accuracy or performance budgets:

1. Scalar-double WGS 84 geodetic/ECEF conversions, origin subtraction/reconstruction, and feature-to-local transforms must agree with independent PROJ reference vectors within **1 mm** over tested planetary coordinates. The existing Gate C double-build origin-reconstruction run measured a maximum arithmetic residual of `0.000000000276 m`; that is representation evidence only and does not establish source geographic accuracy.
2. Adjacent tiles using the same source asset, datum, LOD and shared source sample coordinates must contain exactly equal shared edge values. If a resampling path cannot produce identical edge samples, report its measured residual and independently justify any acceptance limit from the actual algorithm and source evidence.
3. Renderer and collision geometry use the same validated vertices/topology. Feature, terrain and collision transforms reuse one global address and the same local frame, with arithmetic alignment residual no greater than **1 mm**.
4. LOD/source changes preserve the WFG-1 geographic address and disclose source/quality changes. No universal elevation-accuracy or LOD-transition height tolerance is invented; evaluate observed differences using source identity, quality metadata and the exact resampling/transition method.
5. The CopDEM statistical figures above are contextual dataset uncertainty, not guaranteed per-cell error. Overture feature location quality and GEBCO heterogeneous bathymetry uncertainty are captured from the actual source records; no unsupported threshold is assigned.

### Representation and rebase constraints

WFG-1 address identity is independent of source-native sample spacing and runtime representation LOD. Raster sample coordinates follow the declared affine origin and registration rule; the adapter does not clamp or shift samples onto tile bounds. A half-open source grid must provide a separate boundary-support ring for exact mesh edges. Polar edges use one shared longitude-zero pole vertex and a deterministic fan. At the antimeridian, the last tile's normalized -180 east endpoint is compared in the local edge order as unwrapped +180.

Global ECEF coordinates and the tile tangent origin remain scalar binary64 values. A terrain, road, building, water, land-cover or vegetation mesh receives local vectors only after subtracting the current validated ECEF origin. The maximum absolute local component of 250,000 m is an explicit domain for a single installed tangent chunk. Beyond it the manager rebases or unloads the tile; it does not place Earth-radius coordinates into single-precision Godot vectors. The 1 mm coordinate/origin and render/collision criteria measure numerical representation only. They do not upgrade source accuracy or make a source DEM's statistical accuracy a per-sample guarantee.
